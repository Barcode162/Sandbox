# Sandbox
Bunch of things when I want to start from nowhere and export after.

Every project here is built by **[the Bureau](bureau/README.md)**, a multi-agent organization that lives in this repo. It researches, designs, builds in parallel, reviews adversarially, takes the work through a board of directors, and upgrades itself after every mission.

```
/bureau build me <anything>
```

- Projects land in [`projects/`](projects/), each self-contained and exportable.
- How the Bureau works: [`bureau/README.md`](bureau/README.md) · constitution: [`bureau/CHARTER.md`](bureau/CHARTER.md) · the standard: [`bureau/QUALITY_BAR.md`](bureau/QUALITY_BAR.md)
- State of the organization: `python3 bureau/bin/bureau status`
