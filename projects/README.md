# Projects

What the Bureau builds. One folder per project, each **self-contained** so it can be copied out of Sandbox and live on its own:

- its own `README.md`: what it is, how to run it, how to verify it, controls or usage
- its own dependency manifest and lockfile
- one command to run it and one command to verify it

The mission record behind each project (brief, design, plan, reviews, board votes, retro) lives in `bureau/missions/`, linked from the project's README.
