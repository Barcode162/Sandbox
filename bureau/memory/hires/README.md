# Hires

One folder per hire made through `/bureau-hire`:

- `agent.md`: the recruiter's draft agent definition, installed to `.claude/agents/<name>.md` once approved
- `case.md`: the gap, why existing roles can't cover it, how it will be used, and the expected impact
- `board-<director>.md`: each director's verdict

Rejected hires stay here too, as a record of what was considered and why it was turned down.
