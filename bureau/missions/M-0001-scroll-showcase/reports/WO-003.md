## What I built
This WO adds one source for every design token and every user-facing string in *Bent Light*:
- `tokens.css` holds all §13.1 colours (dark scheme switches `--wall` and `--wall-deep` only), §13.2 type, §13.3 spacing and §13.5 motion, including `--idle-ms: 1200` and `--placard-ms: 3000`.
- `tokens.js` mirrors the colours as hex, rgb and computed WCAG Y. It also exports the contrast and compositing helpers.
- `copy.js` holds every §12.1 string verbatim, plus the C7 credit, `sceneLabel` and a `format()` that refuses to leave a placeholder unfilled.
- `phrases.js` has the §7.5 table with `placardPhrase`, `placardLabel` and `admireAnnouncement`.
- `reduced.js` has the §10.4 `stillPlan`.

All four JS modules are pure and typecheck against WO-001's `types.d.ts` (`CoreCopy`, `CorePhrases`, `CoreReduced`, `CoreTokens`).

## Self-review against the quality bar
- **Purity.** The modules contain no DOM, clock, `Math.random` or `console`. The grep's only hit is the word "window" in a comment. Invalid input throws `RangeError`: non-finite p or G, or a scene id outside 1–6. p and G clamp to [0, 1].
- **Placeholders.** `format()` throws if a placeholder is unfilled, and a test limits placeholders to the four declared templates and the spec's own keys.
- **Credit.** The C7 credit wording stands, as the CEO notes allow (§12 is silent on it). I checked its claim against the shipped licence: line 1 of the package `LICENSE` reads `Copyright 2020 The Space Grotesk Project Authors`.
- **Test ids.** My dev test titles start with `[WO-003]`. I moved `#23`, `#39` and `U-6` into parentheses so the K18 manifest reader cannot credit dev tests for spec ids.
- **Removed.** A golden "≥ 10:1" margin I had invented was not in the spec. I replaced it with the measured worst case (the white beam) as a sanity check on the compositing direction.

## Known gaps, risks, follow-ups
- **`npm run verify:quick` has not been run**, because `scripts/verify.mjs` does not exist yet. My unit tests and typecheck pass on their own. The CEO's wave-0 join run is the real gate.
- **Typecheck is red overall** because of one error in WO-002's `tests/unit/dev/core/geometry.test.js:297`. That file is not mine.
- **Gutter mismatch with classic scrollbars.** `--gutter` uses `min-width` media queries, which measure the viewport including the scrollbar, while `viewport()` uses `clientWidth`. With classic scrollbars (e.g. Windows at 1440 px) the CSS gutter (40) can differ from the JS gutter (32). Headless tests hide scrollbars, so they will not catch this. See Requests.
- **`--font` is not defined in `tokens.css`.** The composite `--type-*` tokens reference `var(--font)`, which WO-001 defines in `base.css`, as its order requires. Atomic size, leading and weight tokens are also exported.
- **Not specified, so I chose:**
  - `--ease-in: ease-in`, for the §7.4 caption hand-off, which says "ease-in" with no token.
  - `--focus` as a two-ring box-shadow composite, plus its parts (inner, outer, width, offset).
  - Mode S alternates exist as `*-mode-s` tokens, though they are not used in Mode G.
