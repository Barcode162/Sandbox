2. **Versions exist.** `npm view` → `typescript@6.0.2: 6.0.2`, `@axe-core/playwright@4.14.0: 4.14.0`, `pngjs@7.0.0: 7.0.0`, `axe-core@4.14.1: 4.14.1`, `@playwright/test@1.63.0: 1.63.0`. `node --version` → `v22.23.5`.
3. **Probe A6 re-run.** `node --test tests/unit/` → `exit=1`, `not ok 1 - tests/unit … ERR_TEST_FAILURE`. The quoted glob → `# pass 1`. A failing test → `exit=1`, and an unresolved import → `exit=1`. So the glob is right, **but** a glob matching nothing → `# tests 0 … exit=0`. A typo or a moved directory makes the unit step pass vacuously.
4. **Playwright config semantics (1.63.0, installed in scratch).** Per-project `workers` is supported (`types/test.d.ts:740-757`, "workers limit for this project"). The default testMatch is `**/*.@(spec|test).?(c|m)[jt]s?(x)` (`test.d.ts:696`), so **`tests/perf/scroll.perf.js` is not discovered**: `--list` shows only the e2e test, and `--project=perf` → `Error: No tests found`, `exit=1`. With `--pass-with-no-tests`, which is the obvious way to satisfy WO-001's "missing test directories count as 0 tests", it gives `exit=0`, and the perf step would then pass forever without running.
5. **`page.clock` vs CSS transitions** (`clock.mjs`). After `install` and `pauseAt`, adding the class that starts a 900 ms opacity transition, then `runFor(450)` → opacity still `1`. 500 ms of *real* time while paused → `0.444`. **CSS transitions run on wall time and ignore the fake clock.** E-A3's "sampled every 50 ms of clock time" and #31's "900 ms fade" cannot be measured as written.
6. **A deterministic alternative works** (`seek.mjs`). `document.getAnimations()[0].pause(); a.currentTime = t` with an opacity transition of 900 ms and a 200 ms delay → `{0:1, 200:1, 650:0.5, 1100:0}`, which is exact.
7. **Probe A1 premise.** ESM `import` ignores `NODE_PATH` (tooling §3c). WO-005's `spike.mjs` lives in the dossier, where there is no `node_modules`, and runs in wave 0 in parallel with WO-001's `npm ci`. As specified it cannot `import` playwright. Its stated command `node evidence/spikes/s4-canvas/spike.mjs` is also relative to the project root under the plan's ground rule (`plan.md:6`), which is the wrong place.
