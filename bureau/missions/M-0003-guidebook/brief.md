## The ask (verbatim)
> Add a lot of data that will help understand how I can use this to retrieve data but the thing is I don't what sort of information I need specifically

## What the Owner actually wants
They don't know what to store yet. Give them a large, realistic example memory that shows, by doing, what kinds of things are worth storing and every way of getting them back out (word, neighbourhood, route, lens, pathway), with in-memory guidance on what to try.

## Definition of done
1. A second memory, the Guidebook, of 140+ everyday lights in 10+ clusters, all five kinds, three time lenses (Today / Last year / Next year) that genuinely disagree.
2. "Start here" + "Try" notes that name concrete things to try; every promised answer is asserted by a unit test.
3. Opened from the ••• menu through the existing confirm-before-replace path; loads on demand (no first-paint cost); the bundled seed and its tests are untouched.
4. A browser test opens it, switches lens, searches, races the featured route; screenshots G1–G4 looked at.
5. README section; `npm run verify` green. No secrets stored.
